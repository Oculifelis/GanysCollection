# Gany's Collection

A port of ganymedes01's Gany's Nether, Gany's End and Gany's Surface for NeoForge 26.1.2, combined in one mod. Recipes, crops, loot and other tables live in datapack JSON, so packs can change them.

Requires Fundamentum.

Original mods by ganymedes01 (Unlicense). Port by Oculifelis.
